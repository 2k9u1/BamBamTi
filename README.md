# 응원 문구 뽑기 · GitHub 연수 실습

버튼을 누르면 일반적인 응원 문구를 보여 주는 정적 웹앱입니다. 개인을 식별하는 정보는 입력받지 않습니다.

## 실행

다운로드 또는 Clone한 폴더의 `index.html`을 브라우저로 엽니다. 설치 명령, 계정, API 키, 서버가 필요하지 않습니다.

## 파일

- `index.html`: 화면, 디자인, 동작이 들어 있는 앱
- `.gitignore`: Git으로 기록하지 않을 파일 규칙
- `.env.example`: 환경변수 파일의 모양을 보여 주는 가짜 예시. 이 앱에서는 읽거나 사용하지 않습니다.

## 실습

화면 제목 한 가지를 수정하고 실행 확인 → 변경 파일 확인 → Commit → 내 저장소로 Push → 변경 이력에서 수정 내용 확인 → 디자인 변경 커밋을 Revert → 복구 기록 Push 순서로 연습합니다.

## 공개 전 확인

실제 학생 이름·사진·학번·성적·상담기록, API 키, 비밀번호를 넣지 않습니다. `.env`를 업로드하지 않습니다. 이 앱은 인증·데이터 저장·외부 통신을 구현하지 않았습니다.

이 예제는 이번 연수 자료 작성을 위해 새로 작성한 코드입니다. 배포 라이선스 선택은 자료 소유자가 결정하도록 별도 LICENSE 파일은 포함하지 않았습니다.
